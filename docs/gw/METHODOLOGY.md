# GW 2026 交通量増減率 分析手法

## 分析の目的

大型連休（GW）2026 期間中の一般国道における交通量の変化を、
通常期（前2週同曜日）と比較して増減率として定量化する。

## 対象データ

| 項目 | 内容 |
|---|---|
| データソース | JARTIC オープン交通データ API（WFS 2.0.0） |
| 道路種別 | 3（一般国道）のみ。高速道路（道路種別=1）は対象外 |
| 様式 | 様式2（常設トラカン）+ 様式4（CCTVトラカン）1時間データ |
| 観測点数 | 1,662点（GW・基準期間の両方にデータがある点、うち有効 1,633点） |
| 様式2のみ版 | 1,017点（`--shoshiki2-only` 使用時、うち有効 1,010点）★ウェブマップはこちらを使用 |

## GW 期間

**2026年4月29日（火）〜 5月6日（水）の8日間**

```
4/29(火) 4/30(水) 5/1(木) 5/2(金) 5/3(土) 5/4(日) 5/5(月) 5/6(火)
```

## 比較基準期間の定義

各 GW 日に対して「通常期」を以下のルールで定義する。

> **各 GW 日の 1週間前・2週間前の同曜日**の24時間データを基準値として使用

| GW日 | 比較日①（−1週・同曜日） | 比較日②（−2週・同曜日） |
|---|---|---|
| 4/29 (火) | 4/22 (火) | 4/15 (火) |
| 4/30 (水) | 4/23 (水) | 4/16 (水) |
| 5/1  (木) | 4/24 (木) | 4/17 (木) |
| 5/2  (金) | 4/25 (金) | 4/18 (金) |
| 5/3  (土) | 4/26 (土) | 4/19 (土) |
| 5/4  (日) | 4/27 (日) | 4/20 (日) |
| 5/5  (月) | 4/28 (月) | 4/21 (月) |
| 5/6  (火) | **4/29 (火)** ⚠️ | 4/22 (火) |

> **⚠️ 注意**: 5/6 の比較日①は 4/29 であり、これは GW 初日と一致する。
> 4/29 のデータは GW 平均と基準期間の両方に含まれる。

## 交通量の定義

1時間ごとの交通量 = 上り小型 + 上り大型 + 下り小型 + 下り大型

- 車種判別不能は含まない
- 4値のうち1つでも欠測（null）がある時間帯はその時間を除外

## 増減率の計算式

```
GW_avg  = GW期間（4/29–5/6）の有効1時間値の算術平均
BL_avg  = 比較基準期間（前1週・前2週同曜日）の有効1時間値の算術平均
増減率(%) = (GW_avg / BL_avg − 1) × 100
```

- 有効1時間値が GW・基準の両期間で 1件以上ある観測点のみ集計
- `BL_avg = 0` の場合は NaN（欠損）として除外
- 最大有効時間数: GW 192時間（8日×24h）、基準 384時間（16日×24h）

## 都道府県集計

1. 観測点の座標と都道府県ポリゴン（dataofjapan）を空間結合（`within`）
2. 未割当点（沿岸・離島）は `sjoin_nearest`（EPSG:32654 投影後）で最近傍割当
3. 都道府県値 = `(都道府県内観測点の gw_hourly_avg 合計 / bl_hourly_avg 合計 − 1) × 100`（**交通量加重平均**）

都道府県ポリゴン出典: [dataofjapan/land](https://github.com/dataofjapan/land)（`nam_ja`フィールド）

## 出力ファイル一覧

| ファイル | 内容 |
|---|---|
| `gw_stations.parquet` | 観測点別増減率（様式2+4、有効1,633点） |
| `gw_pref.parquet` | 都道府県別増減率・交通量加重平均（全データ） |
| `gw_stations_s2.parquet` | 観測点別増減率・様式2のみ（有効1,010点）★ウェブマップ使用 |
| `gw_pref_s2.parquet` | 都道府県別増減率・交通量加重平均・様式2のみ ★ウェブマップ使用 |
| `gw_backdata.csv.gz` | 時刻別生データ（全データ版） |
| `gw_backdata_s2.csv.gz` | 時刻別生データ（様式2版） |

属性定義は [CLAUDE.md の「GW 増減率分析」セクション](../../CLAUDE.md) を参照。

## 実行方法

```bash
# 全データ版（様式2 + 様式4）
python scripts/analyze_gw.py

# 様式2のみ版（APIから常設トラカン局コードを取得してフィルタ）
python scripts/analyze_gw.py --shoshiki2-only
```

## 注意・制限事項

- **参考値**: JARTIC データは参考値であり、国土交通省の正式調査結果ではない
- **CCTVトラカンの品質**: 様式4（CCTVトラカン）は照度不足・映像不良等で欠測が多い場合がある。様式2のみ版（`_s2`）の方が精度が高い可能性がある
- **4/29 の二重計上**: 上記の比較基準定義の都合上、4/29 のデータが GW 平均と基準平均の両方に含まれる
- **高速道路は非対象**: JARTIC API の道路種別=1（高速道路）は本分析に含まれていない。参照画像等が高速道路を含む場合は観測点数・増減率が異なる
- **様式4の地域偏在**: 近畿地方整備局のCCTVトラカンは様式4なし（様式3のみ）のため、様式2+4 版でも近畿の CCTV 局は1時間データに含まれない
